# История изменений — Shinra Tensei

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Номера версий условные: проект ведётся с 15.10.2026.

## [0.8.0] — 16.10.2026

### Добавлено
- **Своя папка для писем (.eml) у каждого ящика.** В окне ящика появился блок «Куда сохранять
  письма»: общая папка архива или своя папка (кнопка «Обзор…»). Под выбором показан итоговый путь,
  например `D:\Почта\Иванов\ivanov@mail.ru`.
- Проверка, что в выбранную папку можно записывать, при сохранении настроек ящика.
- **Перенос уже скачанных писем** при смене папки: «Перенести письма» / «Не переносить» / «Отмена».
  На том же диске перенос мгновенный; на время переноса ящик заблокирован, в таблице виден статус.
- Перенос отменяется без изменений, если в новой папке уже есть письма этого ящика.

### Изменено
- Своя папка ящика учитывается везде: загрузка, «Открыть архив», просмотр писем, экспорт в PST.
- Просмотрщик показывает ящики и из общей папки архива, и из их собственных папок.

### Исправлено
- Смена адреса e-mail у ящика больше не теряет связь с уже скачанными письмами: программа
  предлагает перенести их.

## [0.7.0] — 16.10.2026

### Добавлено
- **Окно экспорта стало отдельным (немодальным).** Пока идёт экспорт, главное окно, загрузка почты
  и просмотр писем продолжают работать. Можно запустить несколько экспортов одновременно.
  У окна своя кнопка на панели задач, его можно свернуть.
- **Журнал во вкладках:** вкладка «Все» и отдельная вкладка для каждого ящика. Ход экспорта
  дублируется во вкладку ящика с пометкой `[PST]`. Выбор ящика в таблице открывает его вкладку.
  Вкладка ящика, завершившегося с ошибкой, подсвечивается.
- **Отчёт об экспорте** `<e-mail>_отчёт.txt` рядом с PST и кнопка «Открыть отчёт». Для каждой
  части: имя файла, размер, число писем, общий период и список папок с количеством писем и
  датами «с — по» (по дате получения).
- **Настраиваемый размер одной части PST:** от 0,5 до 50 ГБ, по умолчанию 10 ГБ. Значение
  запоминается.
- Поддержка чтения сжатых писем `.eml.gz` во всех частях программы (сжатие пока не включается).

### Изменено
- Письма внутри каждой папки записываются в PST по дате получения: каждая часть покрывает
  непрерывный период, без перекрытия дат между частями.
- Точное деление на части: программа заранее оценивает размер служебных структур и следующего
  письма, поэтому каждая часть не превышает заданный размер. Превысить его может только часть,
  в которой одно письмо крупнее самого лимита; об этом пишется в журнал.
- При закрытии окна экспорта или программы во время экспорта текущий PST-файл корректно
  дописывается, чтобы он не был повреждён.
- Числа в журнале экспорта отображаются с разделителями (`64 000 писем`).
- Индекс просмотрщика переведён на новую версию; индекс прошлой версии подхватывается без
  повторного разбора писем.

### Исправлено
- Порядок писем при экспорте: раньше файлы сортировались как строки, и письма внутри папки
  шли не по порядку.

## [0.6.1] — 15.10.2026

### Добавлено
- **Значок скрепки** для писем с вложениями в просмотрщике. Программа рисует его сама цветом
  темы, поэтому значок хорошо виден в тёмной и светлой теме и на выделенной строке. Если вложений
  несколько, рядом показано их число; при наведении — подсказка с названиями файлов. Скрепка
  стоит также в заголовке столбца (сортировка) и в списке вложений письма.
- Строка «Вложения: N» в карточке письма.

### Исправлено
- Скрепка ставилась письмам без вложений, например рассылкам со встроенными логотипами.
  Теперь список писем и предпросмотр считают вложения одинаково.
- Пересланное письмо показывается как одно вложение `<Тема>.eml`, а не набор отдельных частей.

## [0.6.0] — 15.10.2026

### Добавлено
- **Проценты в прогрессе загрузки:** `12 345 / 90 000 (13%)`; если новых писем нет —
  «Новых писем нет (100%)».
- **Прогресс экспорта:** полосы для текущего ящика и для всех выбранных ящиков, с количеством
  писем и процентами; надписи «Запись структуры PST…» и «Проверка файла…».
- **Галочки для выбора нескольких ящиков.** Щелчок по заголовку столбца ✔ отмечает или снимает
  все. Запуск, остановка, удаление и экспорт работают с отмеченными ящиками, а если галочек нет —
  с выделенным.
- В окне экспорта кнопки «Отметить все» / «Снять все»; отмеченные в таблице ящики выбраны заранее.
- **Контекстное меню по правой кнопке мыши:** запуск загрузки писем, экспорт в PST, просмотр писем,
  изменение и удаление ящика, а во время загрузки — «Остановить загрузку». Если щёлкнуть по одному
  из нескольких отмеченных ящиков, действие применяется ко всем отмеченным.

### Изменено
- **Предел одного PST-файла увеличен с ~1,9 до 10 ГБ.** Добавлены служебные страницы FMap и
  FPMap для файлов больше 2 ГБ; их расположение сверено с официальной библиотекой Microsoft
  `outlook-pst-rs`.
- Самопроверка PST теперь проверяет расположение и контрольные суммы страниц FMap и FPMap.
- Снижено потребление памяти при экспорте больших ящиков: около 120 МБ на файл 2,4 ГБ.

## [0.4.1] — 15.10.2026

### Исправлено
- **Outlook не открывал PST** («Сервер недоступен…»). По отчёту SCANPST:
  - все блоки в цепочке данных, кроме последнего, заполняются полностью — это требование Outlook;
  - исправлены позиции служебных колонок RowID и RowVer в таблицах;
  - наборы колонок таблиц приведены к обязательным для Outlook;
  - счётчики номеров объектов в заголовке учитывают все объекты, включая вложения;
  - свойство пароля хранилища присутствует всегда (0 — без пароля), у корневой папки есть имя.

### Изменено
- Самопроверка PST стала строже: она проверяет те же правила, на которых споткнулся Outlook.

## [0.4.0] — 15.10.2026

### Добавлено
- **Собственный модуль записи PST** по открытой спецификации Microsoft [MS-PST]. Outlook при
  экспорте больше не нужен — ни запущенный, ни установленный.
- Независимый модуль чтения PST для **самопроверки каждого файла** после экспорта: контрольные
  суммы, подписи, B-деревья, таблицы, число писем в каждой папке.
- Пароль на PST без Redemption: до 15 символов, латиница, цифры и знаки.
- Автоматическое деление больших ящиков на части (`_часть2.pst` и т. д.), тогда по ~1,9 ГБ.
- Перенос в PST: тема, отправитель, получатели (Кому/Копия), даты отправки и получения, текст и
  HTML, вложения любого размера, исходные заголовки, статус «прочитано».

### Удалено
- Экспорт через Outlook (COM) и Redemption вместе с зависимостью от Outlook.

### Исправлено
- Ошибки «Невозможно найти объект» при экспорте: они шли от управления Outlook.

## [0.1.0] — 15.10.2026

Первая версия (под названием MailArchiver).

### Добавлено
- Одновременная загрузка нескольких почтовых ящиков по IMAP; число параллельных загрузок
  настраивается.
- Настройки ящика: e-mail, сервер, порт, протокол (SSL/TLS, STARTTLS, без шифрования),
  «Принимать все сертификаты» (просроченные, самоподписанные, старый TLS), логин, пароль,
  кнопка «Проверить подключение».
- Период загрузки: за всё время или с/по дату.
- Загрузка всех папок или одной выбранной (список папок с сервера, кириллица в именах папок).
- Окно при ошибке на письме: «Пропустить», «Пропускать все ошибки ящика», «Повторить»,
  «Остановить»; автоматическое переподключение при обрыве связи.
- Докачка: повторный запуск скачивает только новые письма.
- Хранение писем в `.eml` с сохранением даты получения и флагов.
- Пароли хранятся зашифрованными средствами Windows (DPAPI).
- Экспорт в PST через Outlook (позже заменён, см. 0.4.0).
- Интерфейс по мотивам MailStore, журнал в окне и в файлах.
- Сборка в `.exe`: `build.bat` и GitHub Actions.
