# Shinra-Tensei RU
Параллельная архивация нескольких почтовых ящиков по IMAP с экспортом в Outlook PST.
Интерфейс и логика по мотивам MailStore Home/Server.

## Возможности
- Несколько ящиков одновременно (число параллельных загрузок — в панели инструментов).
- Для ящика: e-mail, сервер, порт, протокол (SSL/TLS, STARTTLS, без шифрования),
  «Принимать все сертификаты» (просроченные, самоподписанные, старый TLS), логин, пароль.
- Период: за всё время или с/по дату.
- Все папки или одна выбранная (кнопка «Загрузить список папок», кириллица поддерживается).
- Ошибка на письме → окно: Пропустить / Пропускать все ошибки ящика / Повторить / Остановить.
  При обрыве связи программа сама переподключается (до 3 раз).
- Докачка: повторный запуск загружает только новые письма.
- Просмотр писем прямо в программе: дерево ящиков и папок, список с датами отправки и получения,
  сортировка, поиск, фильтр по датам, предпросмотр (HTML/текст, встроенные картинки), сохранение вложений и .eml.
- Темы оформления: Системная (следует за Windows), Светлая, Тёмная — переключатель в панели инструментов.
- Экспорт в PST: отдельный .pst на каждый ящик, структура папок и статус «прочитано» сохраняются.

## Где что лежит
- Архив: `Документы\Shinra Tensei\Archive\<e-mail>\<папки>\*.eml` (можно сменить кнопкой «Папка архива…»).
  При обновлении со старой версии (MailArchiver) настройки переносятся автоматически, а уже скачанный архив остаётся на прежнем месте.
- Настройки: `%APPDATA%\Shinra Tensei\config.json` (пароли зашифрованы Windows DPAPI).
- Журналы: `%APPDATA%\Shinra Tensei\logs\`.

## Экспорт в PST
PST-файл собирается **самой программой** по открытой спецификации Microsoft [MS-PST]
(модули `core/pst_writer.py` и `core/pst_reader.py`). Outlook не нужен — ни запущенный,
ни установленный; файл не подключается к профилю Outlook.

- Отдельный файл на каждый ящик, структура папок сохраняется («INBOX» → «Входящие»).
- Переносятся тема, отправитель, получатели (Кому/Копия), даты отправки и получения,
  текст и HTML, вложения (любого размера), исходные заголовки, статус «прочитано».
- Ящики больше ~1,9 ГБ автоматически делятся на части (`_часть2.pst` и т. д.).
- Пароль на PST: до 15 символов, латиница/цифры/знаки (ограничение Outlook).
  Пароль PST защищает только от открытия через интерфейс Outlook, это не шифрование.
- После записи каждый файл проверяется независимым модулем чтения: контрольные суммы,
  подписи, B-деревья, таблицы и количество писем в каждой папке.

Открыть результат: Outlook → Файл → Открыть и экспортировать → Открыть файл данных Outlook.

## Сборка .exe
Вариант 1 — на Windows: установите Python 3.10+ (python.org, отметьте «Add to PATH»)
и запустите `build.bat`. Готовый файл: `dist\Shinra Tensei.exe`.

Вариант 2 — без Python: загрузите папку в репозиторий GitHub, во вкладке Actions
запустится сборка, exe появится в Artifacts.

Запуск из исходников: `pip install -r requirements.txt` → `python app.py`.
